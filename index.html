Privacy

The interface does not create a database by itself. Journal entries are kept in browser local storage.

Uploaded charts are sent only when you press the analysis button and the page successfully reaches the configured API endpoint.

About ChartLens

ChartLens is a structured chart-learning workspace. The product separates the interface from the AI provider so the backend model can change later.

API Architecture

The browser sends multipart form data to /api/analyze.

The Pages Function validates up to five images, preserves their timeframe labels, sends them to the configured AI layer, and returns structured JSON.
