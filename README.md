# Chyrix AI Frontend

Compact white/orange-accent frontend using the supplied Chyrix logo at `assets/chyrix-logo.png`.

## Important
- Frontend is intentionally no-index while under development.
- Payment page is provider-neutral and contains the promo-code field only on the payment page.
- Production authentication, email verification, sessions, usage limits, AI analysis, journal, extension authentication, and payment verification must be enforced by the backend.
- The signup UI validates matching passwords and redirects to the six-digit verification step; the backend must actually send and validate the code before account activation.


### v4 compact UI
Smaller typography, tighter spacing, compact buttons/cards, and denser analyzer presentation while retaining the Chyrix white + orange identity and supplied logo.
