# Chyrix AI — Frontend

Backend-ready static frontend for Chyrix AI.

## Locked product rules
- Only two plans: Free and Pro.
- Pro: $19.99/month.
- Pro includes up to 7 timeframes: 1M, 5M, 15M, 30M, 1H, 4H, D1.
- The 7-timeframe experience is Pro-only; Free is limited to a single timeframe.
- Position Size / Risk Simulator Calculator is Pro-only.
- Browser Extension and Journal are Pro features.
- Promo code `chyrixai` always gives 5% off the selected monthly or yearly amount.
- Yearly base price is $239.88 (19.99 × 12); with promo code it is $227.89 after rounding.
- Signup verification uses an exactly six-digit email code.
- Get Started links to Sign Up; Sign In is separate.
- Hamburger navigation uses the requested 01–11 order.
- Chyrix logo is stored locally at `assets/chyrix-logo.png`.
- Floating support control opens a support interface.

## Pages
- `index.html` — homepage
- `signup.html` — signup
- `verify.html` — six-digit email verification
- `signin.html` — sign in
- `pricing.html` — full pricing page

No backend secrets or API keys are included. Payment, email delivery, authentication persistence, AI analysis, review email delivery, usage enforcement, and production verification are intended for the backend phase.
