# ChartLens AI

Futuristic AI market-analysis frontend.

## Features

- Market Structure
- Key Levels
- Chart Patterns
- Momentum
- Supply & Demand
- Individual confidence percentages
- Overall AI Confidence
- Futuristic AI market visualization
- CSS/SVG candlestick chart
- Dark AI interface
- Cyan and electric-purple accents
- Responsive mobile design
- No external images required

## Cloudflare Pages
